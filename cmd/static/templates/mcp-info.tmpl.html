MCP-Integration

ID-Generatoren in deinem KI-Assistenten

Die ID-Generatoren stehen zusätzlich als MCP-Server (Model Context Protocol) bereit. Damit kannst du dir Test-IDs – etwa für Testdaten oder Demo-Systeme – direkt in deinem KI-Assistenten (z. B. Claude, GitHub Copilot oder opencode) generieren lassen, ohne diese Website zu öffnen. Beispiel: Du fragst im Chat: „Gib mir eine MaLo-ID zum Testen“ – und bekommst eine ID mit gültiger Prüfziffer zurück.

Server-Adresse

Trage in deinem KI-Tool die folgende Adresse als Remote- bzw. HTTP-MCP-Server ein:

{{ .mcpURL }}

Der MCP-Server ist wie diese Website anonym und kostenfrei nutzbar – eine Anmeldung ist nicht erforderlich.

Einrichtung in deinem KI-Tool

Die genauen Schritte unterscheiden sich je nach Tool. Folge der offiziellen Anleitung deines KI-Assistenten und trage dort die oben genannte Server-Adresse ein:

  • Claude Code (Terminal) ↗ 
    claude mcp add --transport http malo-id-generator {{ .mcpURL }}

    Danach im Claude-Code-Prompt /mcp öffnen, um zu prüfen, dass die Verbindung steht und die sechs Tools angezeigt werden.

  • Claude Desktop & claude.ai ↗

    In den Einstellungen unter „Connectors“ einen benutzerdefinierten Connector hinzufügen und die Server-Adresse von oben einfügen.

  • GitHub Copilot in VS Code ↗ 
    {
  "servers": {
    "malo-id-generator": {
      "type": "http",
      "url": "{{ .mcpURL }}"
    }
  }
}
  • opencode ↗

    In deine opencode.json eintragen (Repo-Root oder global unter ~/.config/opencode/opencode.json): 

    {
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "malo-id-generator": {
      "type": "remote",
      "url": "{{ .mcpURL }}",
      "enabled": true
    }
  }
}
